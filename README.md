# TriFuel — Triathlon Coach

A mobile-first, dependency-free Progressive Web App prototype for Olympic triathlon training and race fueling.

## Run

Open `index.html` in a browser. For PWA/service-worker behavior, serve the folder with any local static server (for example `python3 -m http.server 8000`) and open the local address.

## Included
- Personalized athlete profile and race countdown
- Race-day nutrition timeline
- Carb, sodium, and fluid targets
- Product-label calculator
- Training template
- LocalStorage persistence
- Mobile-first responsive UI
- Basic PWA manifest/service worker
